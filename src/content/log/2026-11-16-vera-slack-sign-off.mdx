Reviewers can sign off on a pull request from Slack (v0.8.0). It's new, and I'm still trying it on Vera's own pull requests.

- **A button and a form:** Vera's Slack message has a Sign off button while someone's part is waiting. It opens a form with their roles and Vera's questions, answered in writing, as on GitHub.
- **GitHub vouches for it:** the sign-off is posted on the pull request by the team's own GitHub App. Vera counts it only when that app wrote it, and only for the person whose message the button was in, so nobody can paste one in for someone else.
- **Same path as GitHub:** from there it's an ordinary sign-off. Vera grades the answers, updates the check and its comment, and the Slack message.
- **Next:** a change that collects sign-off from several roles at once in Slack.

Vera's comment on this site's pull requests now has one block per person (v0.6.0).

- **Why:** the comment was laid out by section, so each reviewer had to piece their own part together. On one of this site's pull requests I held three roles and appeared three times.
- **Now:** each person gets their roles and where each stands, a table of where to look (places to check for engineers, the design call for designers, changed docs for docs people), and their questions, which go once they've signed off.
- **Next:** Slack, where each person gets the same block as a message, can ask Vera about the change, and signs off from there.
